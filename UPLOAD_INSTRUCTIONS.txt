------------

2. Tests all 30 Strategy v2 core USDT pairs across:
   - 15m
   - 30m
   - 1h
   - 4h
3. Runs one symbol at a time; each symbol produces all four timeframe results.

5. Adds matrix summary metrics:
   - coverage

8. Shows only the latest result for each pair/timeframe under the current backtest engine.
9. Old engine results remain in the database but are hidden from the clean v2.1 comparison table.

IMPORTANT BACKTEST CORRECTIONS
------------------------------
The previous multi-timeframe engine used two 15m assumptions on every timeframe:

- 24-hour quote volume = rolling 96 bars
- maximum holding period = 96 bars

96 bars is correct for 15m only.

Engine v2.1 now uses the correct equivalents:
- 15m: 96 bars/day; 96-bar maximum hold
- 30m: 48 bars/day; 48-bar maximum hold
- 1h: 24 bars/day; 24-bar maximum hold
- 4h: 6 bars/day; 6-bar maximum hold

All four timeframes therefore use a consistent 24-hour maximum holding period.

DATA EFFICIENCY
---------------
The new matrix downloads one 15m source history per symbol and resamples it locally
for 30m, 1h and 4h. A short /tmp cache also reduces repeated downloads during the
same testing session.

HOW TO RUN
----------
1. Upload/replace all five files.
2. Deploy on Render.
3. Open Backtests.
4. Click "Run full matrix (120)" once.
5. Keep that browser tab open while the matrix is running.
6. The page will test 30 symbols sequentially, four timeframes per symbol.
7. When complete, the page automatically reloads with the clean engine v2.1 matrix.

If you need to interrupt it, use "Stop after current pair". Completed results stay
saved in the database.

LIVE TRADING
------------
Do not change the live gate because of any individual backtest result. Historical
backtests are evidence for strategy evaluation, not proof of future profitability.
Keep live trading locked while the paper and backtest evidence is still developing.
